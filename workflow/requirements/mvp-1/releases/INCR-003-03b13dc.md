## What was deployed
Scoring and match state tracking for the cricket game. The Match aggregate now processes delivery outcomes, updates InningsProgress immutably after each delivery, detects boundaries (4 and 6 runs), tracks wickets and overs, handles wides and no-balls (1 run, ball re-bowled), determines when the innings is complete (20 overs, 10 wickets, or target reached), and calculates the match result (Win, Loss, Draw). Domain events are emitted for all significant scoring milestones.

## How to validate it works
1. Create a chasing match: `Match.create(matchId = "test", groundId = "g1", maxOvers = 20, maxWickets = 10, bowlerRosterIds = listOf("b1","b2","b3","b4","b5"), target = 100)`
2. Process a 4-run outcome: `match.processOutcome(Outcome(type = OutcomeType.RUNS, runs = 4, dismissalType = null))`
3. Verify `match.inningsProgress.currentScore == 4`
4. Process 6 legal deliveries → verify `match.inningsProgress.oversCompleted == 1`
5. Process a wide → verify score increases by 1 but ballsThisOver does not increment
6. Score exceeds target → verify `match.isComplete == true` and `match.result == MatchResult.WIN`

## How to validate it fails correctly
1. Complete a match (e.g., score exceeds target)
2. Call `match.processOutcome(...)` again → throws `IllegalStateException: "Match ... is already complete"`
3. Construct `InningsProgress(wicketsFallen = 11, ...)` → throws `IllegalArgumentException`
